# Agent charters

Each file in this folder is the instructions for one AI agent. The code reads the file and sends it to the AI as its instructions, word for word. You can improve an agent by editing its file. No coding needed.

Every charter has the same sections:

- **Your one job**
- **What you do not do**
- **How to decline politely**
- **When to bring in the career coach**
- **How to talk**
- **Safety rules** (the same in every charter)

Keep the wording short and plain. The agents work best when the charter reads like a note to a new teammate.
